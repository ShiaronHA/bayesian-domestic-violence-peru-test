# Bayesian Network Analysis of Domestic Violence in Peru

This project models domestic violence risk in Peru using Bayesian Networks trained on CEM (Centro Emergencia Mujer) registry data from 2017 to 2024 (~330K records). It covers the full research pipeline: data preprocessing, structure learning, parameter learning, inference, and evaluation against Random Forest and Decision Tree baselines.

## Project Structure

```
src/
├── main.py                # Pipeline orchestrator — runs all steps in order
├── data_preprocessor.py   # Raw SAV loading, cleaning, feature engineering, train/val split
├── structure_learner.py   # Bayesian Network structure learning (Hill Climb, PC, GES)
├── parameter_learner.py   # Parameter learning (BayesianEstimator, BDeu prior)
├── bayesian_inference.py  # Exact and approximate BN inference + evaluation
├── expert_in_the_loop.py  # LLM-assisted structure learning (Gemini)
├── random_forest.py       # Random Forest baseline
├── decision_tree.py       # Decision Tree baseline
└── metrics.py             # Shared metrics: accuracy, precision, recall, F1, confusion matrix

data/
└── input_data/            # Raw .sav files (not tracked — download separately)

datasets/                  # Processed CSVs generated by data_preprocessor.py
models/                    # Saved .pkl model files
results/                   # Metrics CSVs, classification reports
plots/                     # Confusion matrices, distribution plots
uploads/                   # Categorical mappings, dtype definitions, outlier logs
dag/                       # DAG visualizations
```

## Data

Raw data is not stored in this repository due to file size. Download from Google Drive and place the files in `data/input_data/`:

[Raw Data Files](https://drive.google.com/drive/folders/1Ge8z7mlQg2qGoBehYEhLS8oN5sAhvAQx?usp=drive_link)

Required files:
- `BD Registro de Casos del CEM - Año 20XX.sav` (2017–2024)
- `Poblacion_distritos.xlsx` (district population for violence ratio calculation)

## Setup

1. **Clone the repository:**
    ```bash
    git clone https://github.com/ShiaronHA/bayesian-domestic-violence-peru-test.git
    cd bayesian-domestic-violence-peru-test
    ```

2. **Create and activate a virtual environment:**
    ```bash
    python -m venv venv
    venv\Scripts\activate        # Windows
    source venv/bin/activate     # Linux/macOS
    ```

3. **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4. **Download raw data** into `data/input_data/` (see link above).

## Running the Pipeline

Run the full pipeline end-to-end:
```bash
cd src
python main.py
```

Or run each module independently:
```bash
python data_preprocessor.py    # Step 1: preprocess raw data
python structure_learner.py    # Step 2: learn BN structure
python bayesian_inference.py   # Step 3: run inference and evaluate
python random_forest.py        # Step 4: Random Forest baseline
python decision_tree.py        # Step 5: Decision Tree baseline
python expert_in_the_loop.py   # Step 6: LLM-assisted structure learning (requires GEMINI_API_KEY)
```

### Expert-in-the-Loop (Step 6)

Requires a Gemini API key set as an environment variable:
```bash
# Windows
set GEMINI_API_KEY=your_key_here

# Linux/macOS
export GEMINI_API_KEY=your_key_here
```

## Experiment Configuration

Key parameters are defined as module-level constants at the top of each file — no need to modify function bodies to run different experiments.

| File | Key constants |
|------|--------------|
| `data_preprocessor.py` | `VAL_SIZE`, `NULL_THRESHOLD`, `BINARY_MIN_FREQ`, `MAX_CARDINALITY` |
| `structure_learner.py` | `SAMPLE_SIZES`, `ALGORITHMS`, `MAX_INDEGREE`, `REQUIRED_EDGES` |
| `bayesian_inference.py` | `MODEL_TYPE`, `MODEL_PATH`, `INFERENCE_TYPES`, `MAX_PREDICTIONS` |
| `expert_in_the_loop.py` | `LLM_MODELS`, `EXPERIMENTS` |

## Target Variable

`NIVEL_DE_RIESGO_VICTIMA` — victim risk level, ordinal: `LEVE` < `MODERADO` < `SEVERO`.
